About Me

Hi, I'm Dhiraj Pal, a B.Sc. IT graduate and Python Backend Developer with 1+ year of experience, including internships and full-time development.

I specialize in building backend applications and RESTful APIs using Python, Django, Django REST Framework, FastAPI, and PostgreSQL. I also work with Django ORM, SQL, authentication, and role-based access control (RBAC).

At Elink Software Technologies Pvt. Ltd., I worked on ELINKJAL – Non-Revenue Water (NRW) Water Distribution Management System. As the sole developer on the project, I handled the UI, backend, and database, including REST APIs, hierarchical location management, OTP-based password reset, interactive maps, and real-time dashboards.

Previously, as a Jr. Backend Developer Intern at Sky Need Solution Pvt. Ltd., I developed an HR Management System using FastAPI and PostgreSQL, implementing employee CRUD APIs, attendance tracking, leave management, and email notifications.

I also built a Shopee E-Commerce Web Application as a college project using Django and SQLite, featuring user authentication, product search, price sorting, cart management, and checkout.

I enjoy solving backend problems, designing reliable APIs, working with databases, and building practical applications. I'm looking for opportunities as a Junior Python Developer, Django Developer, or Backend Developer.
